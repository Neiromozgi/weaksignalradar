# 02 — Product Scope

**СННИТ РАДАР** — модульная evidence-grounded система обнаружения, квалификации и ранжирования сигналов новых/зарождающихся научно-исследовательских технологий.

Система ищет объекты, которые:
- ещё относительно малы в reference domain;
- растут и ускоряются;
- несут новое техническое содержание;
- подтверждаются независимыми наблюдениями/акторами/каналами.

## Не является

- поиском новых рынков;
- LLM-оценкой «на глаз»;
- вероятностью успеха технологии;
- полной WSR B0/B;
- системой, где отсутствие данных = отсутствие технологии.

## Runtime vs Target

**Runtime / hackathon:** реальные источники, реестры, A–E, sufficiency, filters, ranking, UI, reproducibility.

**WSR target:** richer evidence verification / Distinctness / Emergence / Maturity / Evidence Sufficiency / extended lineage.

Каждый блок в README/презентации должен иметь реальный статус: `IMPLEMENTED`, `PARTIAL`, `ON_DEMAND`, `DESIGNED`, `TARGET`.
