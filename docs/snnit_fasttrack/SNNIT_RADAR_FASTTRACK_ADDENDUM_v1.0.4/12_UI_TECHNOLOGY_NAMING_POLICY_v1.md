# 12 — UI TECHNOLOGY NAMING POLICY v1

**Project:** СННИТ РАДАР (WSR)  
**Status:** `APPROVED / FROZEN DISPLAY POLICY`

## 1. Основное правило

Во всех пользовательских списках, TOP-15 и Technology Card технология отображается так:

```text
Русское нормализованное название (каноническое название на языке первоисточника)
```

Пример:

```text
Твердотельные аккумуляторы (Solid-state batteries)
```

Если язык первоисточника не английский, в скобках сохраняется именно каноническое название на языке первоисточника, а не принудительный перевод на английский.

## 2. Когда скобки не нужны

Если русское и исходное название фактически совпадают либо исходное название является международной аббревиатурой, не дублировать строку бессмысленно.

Допустимо:

```text
CRISPR
LiDAR
MEMS
```

или русский термин с общепринятой аббревиатурой:

```text
Квантовое распределение ключей (QKD)
```

## 3. Источник оригинального имени

Оригинальное название должно происходить из фактических source documents / Candidate Registry и быть связано с provenance.

Запрещено придумывать английское или иное оригинальное название, если его нет в данных.

Если надёжного исходного имени нет:

```text
Русское нормализованное название
```

без искусственно добавленных скобок.

## 4. TOP-15

В TOP-15 основной визуальный label:

```text
#1 Русское название (Original name)
```

Русское название должно быть первым, так как основной интерфейс продукта русскоязычный.

## 5. Technology Card

В карточке показывать отдельно:

```text
Название: <русское нормализованное>
Оригинальное / canonical name: <source-language name>
Aliases / синонимы: <если есть>
```

В заголовке карточки допустим компактный формат:

```text
Русское название (Original name)
```

## 6. Данные и идентичность кандидата

Локализованное display-name не должно менять внутреннюю идентичность кандидата, candidate_id, deduplication или scoring.

Хранить раздельно минимум:

```text
display_name_ru
canonical_name
canonical_language
aliases
```

или эквивалентную структуру.

Перевод — presentation layer, не новая технология и не новый candidate.

## 7. Перевод

Русское название должно быть технически точным, без маркетингового перефразирования.

Если перевод неоднозначен, предпочтительно сохранить более буквальное техническое название и обязательно показать оригинал.

## 8. Acceptance

PASS, если:

- TOP-15 показывает русский label первым;
- оригинальное source-language name показывается в скобках, когда оно доступно и отличается;
- Technology Card хранит/показывает оба имени раздельно;
- aliases не смешиваются с canonical name;
- перевод не влияет на candidate_id/scoring;
- отсутствующее оригинальное имя не выдумывается.
